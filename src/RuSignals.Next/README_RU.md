# RuSignals

Автор: **Herodrine_**.

Пакет советских и российских светофоров и семафоров для Derail Valley и DVSignals. Включает поездные, маневровые и совмещённые выходные сигналы, автоблокировку, обозначения и маршрутные указатели.

## Требования

- Unity Mod Manager 0.27.3 или новее.
- DVSignals 1.1.3 с его зависимостью DVLangHelper.
- RailwaySafetyGadgets — необязательный мод; поддерживаются версии 1.1.2 и 1.1.0.
- Advanced Dispatcher System — необязательный мод; поддерживаются адаптеры сигналов 1.0.0 и 1.0.1.

Зависимости устанавливаются отдельно.

## Установка

1. Закройте игру, сохраните копию прежней версии и удалите её папку из `Mods`, чтобы не загружать два экземпляра мода.
2. Распакуйте папку `RuSignals` из архива в `Mods`. В `Mods/RuSignals` должны находиться `Info.json`, обе DLL и папка `Assets`.
3. Включите RuSignals в Unity Mod Manager.
4. В настройках DVSignals заново выберите пакет RuSignals с ID `ru.signals` и перезапустите игру. Выбор прежней версии автоматически не переносится.

## Настройка

Панель RuSignals в Unity Mod Manager позволяет выбрать светофор по ID, управлять автоматическим, маневровым и пригласительным режимами, выбирать форму щита и опору. Настройки размещения действуют до перезагрузки карты.

При наведении курсора на светофор с удержанием Alt подсказка показывает кружки показания и имя ниже, на штатной табличке DVSignals. Обозначение совпадает с физической табличкой и остаётся доступным у погашенного светофора.

Поездные входные открываются автоматически по свободному маршруту и выбранному положению стрелок, включая приём на боковые и тупиковые пути. Предварительный резерв для них не требуется и при включённом SpecialReservation. Занятость, неверная стрелка и конфликт с чужим резервом сохраняют запрещающее показание.

При заезде за поездной сигнал и выезде обратно задним ходом маршрут освобождается после выхода последней тележки. Сам реверс не требует ручного сброса сигнализации. Состав, оставшийся перед сигналом, не считается занявшим свободный путь за ним.

При установке RailwaySafetyGadgets его адаптер загружается автоматически.
Совместимость с Advanced Dispatcher System подключается автоматически при загрузке его адаптера DVSignals.
ADS 1.0.0/1.0.1 рисует целые физические пути: подсветка длинного пути на его карте не показывает точные границы интервального резерва RuSignals.
